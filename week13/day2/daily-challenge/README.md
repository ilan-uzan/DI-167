Daily Challenge

How to run:

```bash
cd week13/day2/daily-challenge
node app.js
# or run the composed challenge
node challenge.js
```

Modules:
- `greeting.js` exports `greet(name)`
- `colorful-message.js` exports `colorful(msg)` using chalk
- `read-file.js` exports `readData()` async to read `files/file-data.txt`

Example curl: not needed — these are node scripts.
